#+title: ADR-0007: Credentials via .Renviron environment variables
#+date: 2026-07-08
#+filetags: :IODefl:growthdecomp:adr:

* Status

Accepted, 2026-07-08.

* Context

The goal is to instruct users to obtain their own credentials rather than embedding any key.
Among the targeted sources, World Bank and UN national-accounts require no key.
FRED requires a free key, as would BEA if added later.

* Decision

Keys are read from environment variables via =Sys.getenv()=, sourced from the user =.Renviron=.
Fetchers for keyed sources stop with exact setup instructions when the key is unset.
Keyless sources are documented as requiring only the Suggests package.
No key is committed or shipped.

* Consequences

The keyed and keyless paths are clearly separated.
Users configure credentials once in =.Renviron=.
Error messages guide setup at the point of failure.
The package holds no secret material.
