* The constraint that defines this machine

=NIOTs_resultados.rdata= is not here and will not arrive by =git pull=.
It is excluded by =.gitignore= (line 1 is =*.*= with an extension whitelist), and
under the current plan it moves to Zenodo rather than to git.

Consequences.

- =source("global_variables.R")= *fails on its first line*, which loads
  =../etc/Modelo/NIOTs_resultados.rdata=.
  Anything that sources it, or sources =support_functions.R= after it, cannot run.
- =prepare_data()=, =decompose_growth()=, =group_plots()=,
  =verify_reporting_refinements.R= and =tests.R= are all unavailable.
- Verification on this machine is therefore *reading and parsing*, not running:
  =Rscript -e 'invisible(parse(file="code/support_functions.R"))'= works, and
  proves only that the file is syntactically valid.

*Do not close a ticket on a parse check when its own text asks for a runtime
check.* Record the runtime step as outstanding and leave the ticket open.
This repository has already been bitten twice by plan code that parsed cleanly
and failed on first execution: a =get0()= default that resolved to its own
promise, and a zero-growth guard three orders of magnitude too tight.

* Which tickets run here

The tracker carries a label for exactly this.

: gh issue list --state open --label no-data-required

Everything else waits for the machine that holds the data.
If a ticket looks tempting and lacks that label, check whether it needs the data
before starting; if it does and you started anyway, stop and say so rather than
substituting a parse check for the evidence the ticket asked for.

* Tracker mechanics on this repository

- =gh issue view= *fails here* with a Projects-classic deprecation error.
  Read bodies with =gh api repos/:owner/:repo/issues/N --jq '.body'=.
- Sub-issues:
  =gh api repos/:owner/:repo/issues/<map>/sub_issues -F sub_issue_id=<numeric id>=.
- Blocking:
  =gh api repos/:owner/:repo/issues/N/dependencies/blocked_by -F issue_id=<numeric id>=.
- Use =-F=, never =-f=; a string id returns "Invalid request".
  Get the numeric id with =gh api repos/:owner/:repo/issues/N --jq .id=, which is
  not the issue number.
- Claim a ticket *before* working it: =gh issue edit N --add-assignee gpetrini=.

* Conventions that are not negotiable here

- Documents in *Org*, not Markdown.
  The =.gitignore= excludes Markdown, so a Markdown file will silently fail to be
  tracked unless forced.
- One sentence per line. No em-dashes.
- Native pipe =|>=. =ggplot2= over base. Figures to =../figs/= as PDF via
  =save_figs=; tables to =../tabs/= via =knitr::kable(booktabs = TRUE, caption = ...)=.
- Never rename an existing figure or table file.
- Scripts run from inside =code/=.
- =etc/Modelo/= is read-only reference and is never executed (ADR-0012).
