** The 2025 vintage, from #25

- *No script anywhere builds a =NIOTs= object from the 2025 release.* The
  candidate, =scripts/01_baccaro_2025_from_scratch.R=, writes an xlsx.
- *The only working =NIOTs= builders are in =archive/legacy_scripts/=*:
  =compilacao.R= (7 sectors, 1995–2020) and =compilacao_ICIO.R= (45 sectors,
  1995–2018), both CSV-based, composing the fourteen slots in
  =base/salva_dados.R=.
- =ioOECD::parse_niot_tables()= returns 3 of the 14 slots and hardcodes the
  45-sector geometry. =ioOECD::load_io_tables()= *cannot run*: it wants
  =data-raw/ICIO_<version>/NATIODOMIMP/*.csv=, absent, and its =lapply= body
  returns file paths because the =read.csv= call is missing.
- *Coverage: 28 years (1995–2022), 81 country slices, 50 sectors.* A strict
  superset of the 2023 edition; new are AGO, ARE, COD, MMR, STP, TWN, ROW.
- *50 sectors, not 45.* Splits C24A/C24B, C301/C302T309, H49–H53,
  J58T60/J61/J62_63, plus an =IMP_OTHER= row with no domestic counterpart, which
  the 2025 script silently drops. Every 45-sector assumption in =ioOECD=,
  including the 7-sector aggregator, is incompatible.
- 2021 and 2022 are discarded by the script because *deflators stop at 2020*.
  Extending coverage is a deflator question, not a table question.
- =Super Decomposição= vs =Model_OCDE= *is not settled and cannot be settled on
  the second machine*: the former is described as Google Drive under Insync, the
  latter originates on the co-author's MEGA, the string appears nowhere in the
  folder, and there are no Insync mounts there. It changes nothing downstream.
